Мова CSS у веб-дизайні

CSS (каскадні таблиці стилів) — це формальна мова опису зовнішнього вигляду документа, написаного з використанням мови розмітки. Вона відокремлює оформлення сторінки від її структури.

Завдяки CSS один раз описані правила можна застосувати до всіх сторінок сайту, тому зміна кольору чи шрифту займає лічені секунди.

стильові призначення можна задавати трьома способами: внутрішніми, глобальними і зовнішніми таблицями стилів.

Гарне оформлення робить сторінку зручною для читання.

Основні властивості, які використовують найчастіше: font-family, font-size, font-weight, font-style, color, text-align, text-indent, margin і padding.
