Єдине оформлення за допомогою контейнера style

Розділ 1. Що таке CSS

CSS описує зовнішній вигляд HTML-документа: кольори, шрифти, відступи та розташування елементів на сторінці.

Правила CSS записують один раз у контейнері style, і вони діють на всі відповідні елементи документа.

Розділ 2. Селектори

Селектором може бути ім'я тегу, клас або ідентифікатор. У цьому документі використано селектори тегів body, h1, h3, p і div.

Тому всі абзаци та розділи мають однакове оформлення без повторення атрибута style у кожному тезі.

Розділ 3. Переваги глобальних стилів

Код документа стає коротшим, а зміна оформлення виконується в одному місці.
